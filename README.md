### ✨ Features
- ⚡ **One-Click Mockup** - Just upload and download
- 🖼️ **Bulk Processing** - Create 100+ mockups at once
- 📱 **Realistic Mobile Frame** - High-quality iPhone style frame
- 💯 **Free & Offline** - Works directly in browser, no upload to server
- 📥 **HD Export** - Download high-resolution result

### 🛠️ How To Use?

#### For Single Image:
1. Open [Single Image Tool](https://hubcornor-cyber.github.io/BulkMobileMockup/SingleImage.html)
2. Upload your portrait image
3. Click Generate & Download

#### For Bulk Images:
1. Open [Bulk Image Tool](https://hubcornor-cyber.github.io/BulkMobileMockup/BulkImg.html)
2. Select multiple images at once
3. Click Bulk Generate
4. Download all as ZIP
